## Toolchain — read this first

The Xcode CLT Swift on this machine is **broken** (SwiftPM manifest library
exports no symbols; SDK/compiler mismatch). Never run bare `swift`. Use:

```
$HOME/Library/Developer/Toolchains/swift-6.3.3-RELEASE.xctoolchain/usr/bin/swift
```

The Makefile's `SWIFT` variable auto-resolves this — prefer `make` targets.
cmake lives at /opt/homebrew/bin/cmake. This host's route to ghcr.io is flaky
over HTTP/2 (`curl --http1.1` works).

## Commands

- `make setup` — one command for a fresh clone: deps → model → install → launch
- `make deps` — vendor + build whisper.cpp (pinned tag inside scripts/fetch_whisper.sh)
- `make model [SIZE=small.en]` — download a ggml model to App Support
- `make app` / `make install [CODESIGN_IDENTITY="OpenWisper Dev"]` — bundle + sign
- `make dmg` — package dist/OpenWisper.app into dist/OpenWisper.dmg (drag-to-install)
- `make smoke` — offline E2E: tiny.en + Resources/samples/jfk.wav must transcribe
- `swift test` (via toolchain) — swift-testing only; **XCTest does not exist on this host**
- `swift run pill-demo` — visual check of the recording pill
- `swift run window-demo [dir]` — offscreen PNGs of each app-window page, light + dark (6 files), exits 0

## Gotchas

- Tests are swift-testing (`import Testing`), not XCTest — keep it that way.
- ggml's Metal globals abort the process at exit if a `whisper_context` is still
  alive; `LocalWhisperTranscriber.unload()` on terminate + an atexit net in
  WhisperContext.swift handle it. Preserve both.
- `Sources/CWhisper/include/*.h` are copies regenerated by scripts/fetch_whisper.sh.
- The app must be tested **bundled** (`make install`): TCC grants attach to the
  terminal when run via `make run`, and ad-hoc signing resets grants each rebuild.
- Package.swift stays zero-third-party-dependency.
